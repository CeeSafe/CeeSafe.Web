# M2 — HTTP/1.1 server: record

Implementation plan §7 (M2). Toolchain: ceesafec **0.8.0** (`docs/toolchain.md`).

**Status (2026-11-02):** the HTTP/1.1 stack is on main and passes its conformance, interop, pipelining and coalescing
gates. Two things remain:
- the 24-hour fuzz campaign is running;
- `web_server` (task 5: the router, middleware and `Server<S>`) is written but waits for CeeSafe bug **B8**, on branch
  `m2-server`.

## Design decisions, recorded as ADR amendments

| Decision | Why | Where |
|---|---|---|
| `HeaderList` keeps offsets into the head buffer it borrows | CeeSafe v0 has no arrays of views (N0246); CeeSafe ADR 0045 declined lifting it | Web ADR 0003 amendment 1 |
| `ResponseHead` is a reusable builder; framing fields are the writer's; no `Date` | `after` hooks edit the head; no wall clock in CeeSafe (upstream **U12**) | Web ADR 0003 amendment 2 |
| One `Exchange` per request (body and response), not a body and a writer | both need `borrow mut` of the transport, and CeeSafe lends mutably once at a time; neither can be `dyn` (N0267) | Web ADR 0003 amendment 3 |
| Body framing (`ChunkDecoder`, `Encoder`) and the `Application` interface are in `web_http` | `Exchange` decodes and encodes in place, and `Handler` names it | Web ADR 0004 amendment 1 |
| `Middleware.after` gets the request and the head, not the context | the head can be sent inside `exchange.write`, while the handler holds `borrow mut ctx` | Web ADR 0007 amendment 1 |
| Typed state `S` kept; each application writes 2 delegating impls until U10 (the owner's choice, 2026-11-02) | no generic impls in v0 (N0105) | Web ADR 0007 (to amend when `web_server` merges) |

### Defects found by the gates, all fixed

| Found by | Defect | Fix |
|---|---|---|
| hand-tracing the driver tests | HEAD sent the body after GET's `Content-Length` | HEAD counts and drops its bytes |
| hand-tracing | a response that ignored a 100-continue body kept the connection without saying it would close | `Connection: close` once the head knows |
| conformance (h11) | `Content-Length: 005` with `Content-Length: 5` was taken as 5 | only textually identical duplicates collapse (RFC 9112 §6.3) |
| fuzzer, invariant 1 | the scanner's error depended on how the input was split | limits are checked at the byte that breaks them |
| fuzzer, invariant 4 | an error response was lost when the write buffer was full of coalesced responses | flush, then encode again |

## Waiting upstream

| Item | Blocks |
|---|---|
| **B8**: a `Box<dyn I<S>>` parameter can't be stored into a container when `S` is a type parameter | `web_server` (`Router<S>.add`, `Server<S>`'s middleware) |
| **U12**: wall-clock time | the `Date` field (until then the server sends none, as RFC 9110 §6.6.1 allows a server without a clock) |
