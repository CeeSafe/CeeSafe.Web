# M4 — TLS: record

Implementation plan §7 (M4). Toolchain: ceesafec **0.9.2** (U8's manifest `links`, released in 0.8.0). Design: Web ADR
0002 and its amendment 1. OpenSSL on this machine: 3.6.4 (Homebrew `openssl@3`).

HTTPS example and interop with three independent clients. Stages 3–4 remain.
