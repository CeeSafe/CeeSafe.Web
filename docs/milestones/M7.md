# M7 — HTTP/2: record

Implementation plan §7 (M7). Toolchain: ceesafec **0.10.1**. Design: Web ADR 0011, accepted 2026-11-03 with the
owner's four answers (TLS ALPN `h2` and cleartext `h2c` by prior knowledge; server only; priority ignored; push
supported), amendment 1.

**Status (2026-11-03):** in progress, on branch `m7-http2`. Stages 1 (engine) and 2 (driver, `web_server` entry) are
done. Stage 3 (the gate) is under way: h2spec passes, and h2load interoperates. CeeSafe's B16 (a lost wake past
~30 connections) is fixed in 0.10.2, and B17 (throughput past ~2 000 concurrent streams) in 0.10.3 (ADR 0062); the
branch moves to 0.10.3. Open: the cancel stress tests, the fuzz target, and nghttp's checks.

## Delivered

| Where | What |
|---|---|
| `web_http2` (engine, sans-I/O) | HPACK (`HpackDecoder`, `HpackEncoder`, Huffman, the static table generated from RFC 7541 Appendix A), `Frames`, `H2Settings`, `Requests` (RFC 9113 §8 checks), `H2Connection` (stream states, flow control, the guards) |
| `web_http2` (driver) | `serveH2`: one connection task and a task per stream (in a task set), channels between them; push; GOAWAY on drain, idle and error |
| `web_http` | `Exchange.forStream`, `StreamSink`, `HeaderBlock` |
| `web_http1` | `serveFrom`: HTTP/1.1 after the bytes read to choose the protocol |
| `web_server` | `Server<S: Send>`; `run` takes the server; `HttpService` and `serviceOf` choose HTTP/2 by ALPN or preface |
| `examples/https`, `examples/server` | ALPN `h2`; h2c by prior knowledge |
